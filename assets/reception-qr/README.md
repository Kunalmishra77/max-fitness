```

│        [MAX logo]            │
│  Scan once. Train stress-free.│  ← Khand 700, Plate Navy

│      └──────────────┘        │
│                              │
│  Already a member? Confirm   │

│  New? Join in 2 minutes.     │
│  पहले से मेंबर? अपनी जानकारी │
│  और फीस की तारीख दें।        │
│  नए हैं? 2 मिनट में जॉइन करें। │
│                              │
│  Open camera → point at code │
│  Help? Ask reception.        │
└──────────────────────────────┘
```
- Colours: Chalk background, Plate Navy text, Signboard Red accent bar; QR in pure black on white for contrast.
- Print: matte laminate (avoid glossy glare), acrylic stand, placed at counter height away from direct tube-light reflection.
- Test before printing: scan from 1 m with 3 different phones (Android + iPhone) under reception light.
- Also print a small version on the kiosk signage ("New? Scan to join").
- DEMO posters for staging must say "DEMO" diagonally.

## Generating
```
pnpm qr:poster -- --origin https://your-domain            # A4 + A5, source=reception
pnpm qr:poster -- --origin https://your-domain --source counter2
pnpm qr:poster -- --origin https://max-fitness-kappa.vercel.app --demo   # demo posters, marked DEMO
```
Files land here as `qr-{source}-{a4|a5}[-demo]-{host}.svg`. SVG is vector: send it to the print shop as is (or export to PDF at 100%). The demo pair for the current demo site is already here.
